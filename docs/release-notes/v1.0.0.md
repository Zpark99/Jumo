# 주모 v1.0.0 (2026-10-31)

> 국내 주식 **모의투자 + 소셜** 플랫폼. 가상 시드 1,000만원으로 실제 지연 시세에 매매를 연습하고, 종목 이야기를 피드에서 나눈다.

🔗 https://jumo-one.vercel.app · Google 계정 가입 시 시드 1,000만원 지급. 실제 돈은 오가지 않는다.

v1.0.0은 2026-06-20에 시작한 개인 프로젝트의 **동결 릴리스**다. 이 태그 이후 신규 개발은 없고, 머니·보안 버그 hotfix만 진행한다(#144).

## 주요 기능

| 영역 | 내용 |
|------|------|
| 시세 | 한국투자증권(KIS) Open API **지연 시세**. 현재가 50초 캐시, 10호가 3초 폴링. 국내 4종목(삼성전자 · SK하이닉스 · 카카오 · NAVER) |
| 차트 | 캔들 + 거래량, **일/주/월** 전환, 크로스헤어 OHLC, 전체화면 |
| 거래 | 시장가 매수/매도. 체결 즉시 보유 · 잔고 반영. 거래 내역 |
| 계좌 | 총자산 · 누적 손익 · 수익률, 원화 평가금액 추이 그래프(매일 00:00 KST 스냅샷) |
| 소셜 | 글 작성 · 종목 태그, 댓글, 좋아요/싫어요, 리포스트(인용), 팔로우, 공개 프로필 |
| 랭킹 | **누적 수익률** 랭킹(가입 시드 대비, 매일 00:05 · 09:05 KST 자동 집계) |
| 홈 | 코스피 · 코스닥 실데이터, 관심 종목, 랭킹 프리뷰. 해외지수 · 환율 · BTC · 뉴스 · 일정은 **"예시" 배지**가 붙은 목업 |

시세는 로그인 없이 홈에서 볼 수 있고, 종목 상세 · 거래 · 피드 · 랭킹은 로그인이 필요하다. 다크 테마 전용.

## 설계 하이라이트

- **주문 체결 정합성** — 체결은 `execute_order` RPC 하나로 모으고 `SELECT … FOR UPDATE`로 계좌 · 보유 행을 잠근 뒤 검증 → 체결 → 기록을 한 트랜잭션으로 처리. 검증 코드 `V1`~`V6` 반환. 실제 Supabase에서 RPC를 동시 호출하는 동시성 테스트가 매수 · 매도 레이스 8/8 PASS.
- **권한 설계** — 17개 테이블 RLS. `SECURITY DEFINER` RPC(KIS 토큰 조회/저장, 시세 upsert)는 `service_role`만 실행(#137). `accounts` · `orders` · `posts` · `comments`의 클라이언트 쓰기 정책 제거. 랭킹 · 소셜 뷰는 anon 권한 전부 회수, authenticated SELECT만(#180 · #187).
- **0원 체결 차단** — KIS가 `rt_cd=0`인데 빈 값을 주는 경로를 `price_quotes.price > 0` CHECK 제약으로 모든 writer가 수렴하는 지점에서 차단(#121).
- **KIS 초당 2건 제약** — 다건 조회는 순차 호출 + 캐시. 국내지수는 `unstable_cache` 60초(Vercel 인스턴스 간 공유 실측), 현재가 50초 캐시는 체결 신선도 한도(60초)보다 짧게.
- **스케줄 작업 분리** — DB 안에서 끝나는 일(자산 스냅샷, 랭킹 집계)은 pg_cron, 외부 API가 필요한 일(장 마감 후 시세 일괄 갱신)은 Vercel Cron(평일 16시대 KST). 놓친 실행은 "MM/DD 기준" 표기로 드러냄(#165).
- **정직한 표기** — "지연 시세" 배지, 오늘 시세가 아니면 "MM/DD 기준", 실데이터가 아닌 위젯은 "예시" 배지.

## 알려진 제약 · v2

자세한 목록은 [`09-v2-Roadmap.md`](../09-v2-Roadmap.md). 관련 이슈는 not planned로 닫혀 있고 재개 시 reopen.

- **해외 종목 미지원** — KIS 해외주식 API 권한 없음(`EGW02004`). 해외지수 · 환율 카드도 같은 이유로 예시 (#120)

- **뉴스 · 일정은 목업** — 데이터 소스 미확보 (#109 · #110)
- **차트 분봉 없음** — 일/주/월만 (#112)
- 다크 테마 전용 (#51) · 아바타 업로드 없음 (#43) · 시즌(기간별) 랭킹 없음 (#47) · 인기순 정렬 1000건 초과 truncation (#37)
