# 01. PRD — 요구사항 정의서 (v1.0 결과 기준, 2026-11-06 재작성)

> 7월 기획 시점의 자리표시자를 v1.0.0(2026-10-29 태그) **결과**에 맞춰 다시 썼다. 여기 적힌 범위는 전부 운영(https://jumo-one.vercel.app)에서 동작하는 것이고, 하지 않은 것은 Out에 이유와 함께 적었다.

## 개요
**국내 주식 모의투자 + 소셜** 웹 서비스. Google 계정으로 가입하면 가상 시드 1,000만원이 지급되고, 한국투자증권(KIS) Open API의 **지연 시세**로 국내 4종목을 매매 연습하며, 종목 이야기를 피드와 종목별 커뮤니티에서 나눈다. 실제 돈은 오가지 않는다.

## 문제 정의
- 실제 계좌로 투자를 시작하기 전에 **돈을 잃지 않고 매매 흐름(주문 → 체결 → 잔고·보유 반영 → 손익)을 경험**할 곳이 필요하다.
- 혼자 하는 모의투자는 지속 동기가 약하다. 같은 조건(동일 시드)에서 **다른 사람과 수익률을 비교**하고, 종목에 대한 생각을 나눌 수 있어야 한다.
- 개발 관점의 문제: 외부 시세 API의 **rate limit(초당 2건)과 빈 응답**, **동시 주문** 아래에서 잔고 정합성을 지키는 설계를 처음부터 끝까지 직접 만들어 보는 것.

## 대상 사용자
- 주식 투자를 시작하려는 초보자 — 매수/매도·호가·캔들 차트를 실제 시세로 눌러 보고 싶은 사람
- 투자 경험자 중 **원금 리스크 없이** 전략을 시험하거나 남과 수익률을 비교해 보고 싶은 사람
- (v1.0 실제 사용자) 소유자 1명 + 데모 계정 1개. 유저 모집은 하지 않았다

## In — v1.0 범위 (전부 운영 중)

| 영역 | 요구사항 |
|---|---|
| 가입·계좌 | Google OAuth 가입 시 계좌 자동 생성, 시드 KRW 10,000,000. 유저당 계좌 1개 |
| 시세 | KIS 지연 시세. 현재가(50초 캐시) · 10호가(3초 폴링) · 일/주/월 캔들. 국내 4종목(삼성전자·SK하이닉스·카카오·NAVER). 화면에 "지연 시세" 배지, 오늘 시세가 아니면 "MM/DD 기준" |
| 거래 | 시장가 매수/매도. 서버 기준가로만 체결, 수수료 0. 수량·잔고·보유·시세 신선도(60초) 검증 후 거부 사유를 UI에 그대로 표시. 동시 주문에도 이중 체결 없음 |
| 자산 | 총자산 · 누적 손익 · 수익률, 보유 종목, 거래 내역. 원화 평가금액 추이 그래프(매일 00:00 KST 스냅샷) |
| 랭킹 | **누적 수익률**(가입 시드 대비) 랭킹. 매일 00:05·09:05 KST 자동 집계 + 수동 갱신 버튼 |
| 소셜 | 글 작성·종목 태그, 중첩 댓글, 좋아요/싫어요(글당 1개), 리포스트(인용), 팔로우, 공개 프로필, 마이페이지(닉네임·bio·아이콘). 피드는 전역 최신순 / 인기순 |
| 홈 | 코스피·코스닥 실데이터, 관심 종목, 내 투자 요약, 랭킹 프리뷰. 비로그인 열람 가능 |
| 보안 | 17개 테이블 RLS. 잔고·주문 쓰기는 `execute_order` RPC가 유일한 경로. 서버 전용 RPC는 `service_role`만 실행. 소셜·랭킹 뷰는 authenticated만 읽기 |
| 운영 | 개인정보처리방침 페이지. 자산 스냅샷·랭킹 집계는 pg_cron, 장 마감 후 시세 일괄 갱신은 Vercel Cron |
