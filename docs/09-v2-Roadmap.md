## v2 — 실데이터·실시간
- [ ] 해외 종목 복원 (#120) — **KIS 해외주식 API 신청이 선행**(현재 `EGW02004`로 전부 차단). 신청 후 `overseas-price` 경로 구현 + `SUPPORTED_MARKETS`에 `"US"` 재추가. 해외지수·환율 카드 실데이터도 같은 권한으로 열림

- [ ] KIS 웹소켓 실시간 시세 (#119) — 구독 성공 확인됨. 장중 수신 검증 + 서버 릴레이 아키텍처 결정 필요(`approval_key` 브라우저 노출 금지)
