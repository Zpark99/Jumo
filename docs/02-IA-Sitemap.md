## 라우트 구조
```
/                 홈 (시세 개요 · 관심종목 · 실시간 랭킹)
/feed             소셜 피드
/feed/[postId]    글 상세 · 댓글
/stocks/[id]      종목 상세 · 차트 · 주문 · 커뮤니티
/account          내 계좌 (자산 · 보유 종목 · 거래 내역)
/mypage           마이페이지 (공개 프로필)
/login            로그인
```

## 주요 플로우
- 회원가입/로그인 →
- 종목 탐색 → 주문 →
- 글 작성 → 반응/댓글 →
